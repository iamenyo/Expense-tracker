# Python Expense Tracker

A command-line Expense Tracker built with Python.

This project focuses on the backend logic of an expense tracking application. The goal is to develop and test the application's core functionality.


## Features

- Add expenses
- View all expenses
- Edit expenses
- Remove expenses
- Automatically record the expense date
- View expense statistics:
  - Total expenses
  - Number of expenses
  - Average expense
  - Lowest expense
  - Highest expense
- Save expenses to a JSON file
- Load expenses from a JSON file

## Technologies Used

- Python
- JSON
- datetime

## Data Structure

Each expense is stored as a dictionary:

```python
{
    "amount": 5000,
    "category": "Food",
    "description": "Lunch",
    "date": "2026-07-27"
}
```
